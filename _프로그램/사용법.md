# 사용법

## 처음 한 번
1. `구글연동_안내.md`대로 `client_secret.json`을 받아 이 `_프로그램` 폴더에 넣기
2. `실행.pyw` 더블클릭 (처음엔 부품 설치로 조금 걸림)
3. **설정** → **채널 추가** → 칸 채우기 → **로그인** (채널마다)
   - 브라우저에서 그 채널의 구글 계정으로 로그인하고 **채널 선택 화면에서 그 채널**을 고르세요
   - 로그인하면 설정 위쪽에 채널 이름이 표시됩니다. 다른 채널이 표시되면 다시 로그인
4. **저장**

## 3주마다
| 순서 | 누가 | 할 일 |
|---|---|---|
| 0 | 버튼 | **새 묶음 폴더** → `영상/2026-10-19/채널폴더들` 이 생기고 폴더가 열림 |
| 0 | 나 | 채널 폴더마다 영상·SEO 메모장·썸네일 넣기 (안에서는 아무렇게나) + 영상은 Studio에 끌어다 놓기 |
| 1 | 버튼 | **1. 엑셀 만들기** → `업로드목록.xlsx` 생성 |
| 2 | 나 | **엑셀 열기** → 노란 칸만 수정 (제목, 회원우선 O, 예약일시) → 저장하고 **엑셀 닫기** |
| 3 | 버튼 | **2. 정보·댓글 넣기** → 초안에 제목·설명·태그·썸네일, 일부공개, 댓글 |
| 4 | 나 | **3. 고정 탭 열기** → 채널별 버튼 → 탭마다 댓글 고정 (수창 채널은 광고 설문 탭도) |
| 5 | 버튼 | **4. 예약 걸기** → 예약 + 끝난 파일을 `완료/`로 이동 |
| 6 | 나 | 회원우선 영상만 Studio에서 "회원 전용 + 공개 예약" 직접 설정 (창에 날짜·시간 안내) |

- 중간에 멈춰도 같은 버튼을 다시 누르면 **끝난 영상은 건너뛰고** 이어서 합니다.
- 실패한 영상은 엑셀 `오류` 칸에 이유가 적힙니다.

## 설정 항목
- **제목/설명 넣는 자리**: 초안에 이미 있는 틀(템플릿)을 남기고 어디에 넣을지
  - 기준 글자 앞/뒤: 예) 제목 틀이 `【명언】 | 채널명`이고 기준 글자가 `|`면 → `【명언】 새 제목 | 채널명`
  - 표시 문자 바꾸기: 틀에 넣어둔 표시(예: `{제목}`)를 내용으로 바꿈
- **공개 요일·시간**: `월 18:00, 수 18:00, 금 18:00` 처럼. 이미 예약된 마지막 영상 다음 빈 자리부터 채웁니다
- 나머지(카테고리, AI 합성 표시 등): 기본은 **건들지 않음** = Studio 기본 설정 그대로

## 알아둘 것
- YouTube API 하루 한도로 **하루 약 40개**까지 처리됩니다. 넘으면 멈추고 알려주며,
  한국 시간 오후 5시쯤 이후 다시 누르면 이어서 합니다.
- 댓글 고정·광고 설문·회원 전용은 공식 API에 기능이 없어 직접 합니다.

## 폴더 규칙 (이것만 지키면 됩니다)
```
영상/
  2026-10-19/          ← 새 묶음 폴더 버튼이 만듦
    숨겨진동양사/        ← 채널 폴더 (설정의 '영상 폴더' 이름)
      아무 폴더나/ 아무 이름이나   ← 영상, SEO 메모장, 썸네일, 대본 등
    고전/
    중국/
```
- 짝 찾기: 영상 파일 이름의 번호 = SEO의 순번. 썸네일은 같은 이름 → 같은 번호 → 제목 비슷한 것 순서로 찾음
- 못 찾은 것은 1단계 끝에 목록으로 알려줌
- 채널 폴더의 영상이 다 끝나면 그 채널 폴더째 `완료/2026-10-19/채널/`로 옮김
