# 사용법

## 처음 설치 (한 번만)
- [LongAutoUpload.zip](https://github.com/kjg0898-dot/LongAutoUpload/releases/download/download/LongAutoUpload.zip) 받기 → 오른쪽 클릭 **압축 풀기** → `LongAutoUpload` 폴더가 생김 (원하는 곳, 예: 바탕화면으로 옮기기)
- **이후 새 버전은 자동**: 프로그램을 켤 때 새 버전이 있으면 알아서 업데이트하고 다시 켜집니다 (몇 초).
  다시 내려받거나 폴더 이름을 바꿀 필요 없고, 열쇠·로그인·설정·영상·엑셀은 그대로 남습니다.
  켜 둔 채로 받고 싶으면 **더보기 → 업데이트 확인**

## 처음 한 번
1. `구글연동_안내.md`대로 열쇠 파일(`client_secret_….json`)을 받아 이름 그대로 이 `_프로그램` 폴더에 넣기
2. `실행.pyw` 더블클릭 (처음엔 부품 설치로 1~2분, 창이 멈춘 것처럼 보여도 기다리기)
3. **설정** → **채널 추가** → 브라우저에서 그 채널의 구글 계정으로 로그인하고 **채널 선택 화면에서 그 채널**을 고르기 (5분 안에)
   - **나머지는 자동**: 채널 이름·영상 폴더 이름·공개 요일·시간(최근 공개·예약 기록에서)을 채우고,
     "수익 창출 채널인가요?", "회원 기능 쓰나요?" 두 가지만 물은 뒤 저장합니다
   - 숨겨진동양사는 미리 넣어 두었습니다: 설정에서 고르고 **로그인**만 누르세요
   - 설정 위쪽에 "로그인됨: YouTube 채널 '…'"이 그 채널인지 확인. 다르면 다시 **로그인**
   - 제목 넣는 자리 기본값은 Studio 제목 틀의 `]` 바로 뒤입니다. 예) `[숨겨진 동양사] ＜엑셀 제목＞ l 역사 인물 l 고전 | 수면오디오북`.
     제목 틀이 없는 채널(초안 제목이 파일 이름)은 제목을 통째로 바꿉니다

## 화면
- **위쪽 버튼 3개**: ⚙ 설정, 안내, 더보기 (영상·완료 폴더 열기, 빈 묶음 폴더 만들기, 엑셀로 열기, 작업 기록, 단계만 따로 하기,
  썸네일 시험, 업데이트, 청소)
- **파일을 창에 끌어다 놓기**: SEO 메모장·사진(또는 그 폴더)을 여러 개 한 번에 창 아무 데나 놓으면 채널을 묻고 넣습니다
  (메모장 → SEO 넣기, 그림 → 그 영상의 후보 그림. 썸네일 자동 만들기를 끈 채널은 완성 썸네일). 처음 업데이트 뒤 한 번 다시 켜야 켜집니다
- **왼쪽: 카드 4개** — 지금 할 차례인 카드가 노랗게 표시됩니다. 노란 카드의 버튼만 누르면 됩니다.
- **오른쪽: 영상 목록** — 색: 빨강=오류, 파랑=진행 중, 초록=완료, 주황=회원 직접설정
  - **더블클릭** → 고치기 창: 제목(후보 3안 버튼, 글자 수 표시), 예약일시, 회원 우선, 썸네일 없이, 영상ID. **저장하고 다음 ▶**
  - **오른쪽 클릭** → Studio에서 열기, YouTube에서 보기, 파일 폴더 열기, 썸네일 없이 올리기, 정보 넣기를 처음부터 다시
- **아래: 기록** — 무슨 일이 있었는지 차례로 나옵니다

## 3주마다
| 카드 | 누르면 | 내가 할 일 |
|---|---|---|
| **1. 준비 → SEO 넣기** (또는 SEO 메모장을 창에 끌어다 놓기) | 채널 폴더가 생기고 **준비 화면**이 열림 (채널별 탭, 영상마다 칸) | 썸네일 그림을 만들어(Gemini 등) 영상 칸에 **끌어다 놓기** — 영상마다 여러 장 |
| **준비 화면** | 주제마다 **실제 사진 1장**을 찾아(API 키가 있으면) 후보 그림에 합성해 보여줌 | 후보를 **클릭해 고르기**, 제목·썸네일 문구 고치기 (설명·고정 댓글도 보고 고칠 수 있음) |
| **준비 화면 → 최종 썸네일 만들기 (전부)** | 고른 그림 + 실제 사진 + 문구 + 채널 마크로 채널 틀에 맞춰 최종 썸네일 | 마음에 안 들면 그 칸의 **최종 만들기**(새로), **실제 사진 다시 찾기** |
| (그동안) | | 영상을 Studio에 끌어다 놓고 **초안이 될 때까지** 기다리기 (영상 파일은 폴더에 안 넣어도 됨) |
| **2. 자동 처리** | 목록 만들기 → 제목 확인 창(준비 화면 값이 들어가 있음) → 제목·설명·썸네일·일부공개·댓글 → 고정 탭 | **이대로 진행** |
| **3. 댓글 고정** | (2번 끝에 자동으로 열림) | 탭마다 댓글 옆 ⋮ → 고정 |
| **4. 예약 걸기** | 예약 + 확인 + 끝난 채널 폴더를 `완료/`로 | 상태가 **'회원 설정 필요'**인 영상만 Studio에서 회원 전용 공개 직접 설정 |

- 후보 그림 넣는 법 (아무거나): ① 준비 화면의 **영상 칸 위에** 끌어다 놓기(이름 상관없음)
  ② 이름 **맨 앞에 번호**(`3.png`, `3번_a.png`)를 붙여 한꺼번에 놓기 ③ **번호 폴더**(`3/`, `3번/`)째로 놓기.
  이름 중간의 숫자(`Gemini_Generated_Image_7k2…`)는 번호로 보지 않습니다
- 고친 것은 바로 채널 폴더의 `제작.json`에 저장됩니다. **작업표**(더보기·준비 카드)는 보기용 정리본입니다
- 썸네일 문구가 길어 한 줄에 안 들어가면 가운데 띄어쓰기에서 알아서 두 줄로 나눕니다
- SEO를 넣을 때 그 채널의 마지막 묶음에 이미 SEO가 있으면 새 묶음(오늘 날짜) 폴더를 만듭니다

- 중간에 멈춰도 같은 카드 버튼을 다시 누르면 **끝난 영상은 건너뛰고** 이어서 합니다.
- 실패한 영상은 목록에 빨간색으로, 이유와 함께 나옵니다. 고친 뒤 같은 버튼을 다시 누르면 됩니다.
- **작업 중에는 엑셀을 열지 마세요.** 열려 있으면 닫으라고 물어봅니다.

## 썸네일 자동 만들기 (채널마다 켜고 끔)
1. **설정 → 채널 → '썸네일 자동 만들기' 체크**. 고급 설정에 **Claude API 키**를 넣으면 실제 사진까지 자동 (없으면 사진 없이)
2. 고급 설정 → **이 채널 썸네일 틀 폴더 열기** → `로고.png`(채널 마크, 배경 투명), 폰트 파일(.ttf/.otf)을 넣기.
   예시 썸네일을 Claude에게 보내면 `틀.json`(글자 자리·크기·색 조합·사진 칸)을 만들어 드립니다
3. **준비 화면**에서 후보 그림을 고르고 문구를 고친 뒤 **최종 썸네일 만들기** (위 '3주마다' 참고).
   준비 화면에서 안 만들었으면 2. 자동 처리 때 만들고 **썸네일 확인** 창을 띄웁니다

- 글자는 폰트로 찍습니다 (AI가 그리지 않아 한글이 깨지지 않음). 폰트에 없는 글자(이모지 등)가 있으면 만들지 않고 알려줍니다
- 채널 마크는 매번 같은 파일을 같은 자리·같은 크기로 붙입니다. 실제 사진은 마크를 피해서 놓입니다
- 매번 조금씩 다르게: 글씨 색 조합, 글자 쪽(왼쪽/오른쪽), 크기·위치, 사진 기울기
- API 키가 있으면 Claude가 사진을 보고 얼굴·핵심을 가리지 않는 쪽과 강조할 말을 정하고, 위키미디어 공용에서
  **저작권이 풀린(퍼블릭 도메인·CC0) 사진만** 찾아 그중 알맞은 것을 골라 넣습니다 (실제 사진은 주제마다 한 번만 찾음: 검색어·고르기 2번 + 최종 때 배치 1번)
- 고른 그림·문구·실제 사진이 그대로면 다시 눌러도 새로 만들지 않습니다 (돈이 두 번 들지 않게)
- 만든 뒤 기록에 **실제로 쓴 Claude 토큰과 비용**이 나옵니다
- **더보기 → 썸네일 시험 (실제 Claude)**: YouTube는 건드리지 않고 썸네일 하나를 실제로 만들어 봅니다.
  `_프로그램/썸네일_시험.jpg`와 `썸네일_시험_결과.txt`(비용 포함)가 열리니 둘 다 Claude에게 보내주세요

## 설정
- 늘 보이는 칸: 채널 이름, 공개 요일·시간, 수익 창출, 회원 기능, 재생목록(주소 붙여넣기, 여러 개는 쉼표)
- **고급 설정 ▸**: 영상 폴더 이름, 제목·설명 넣는 자리, AI 합성 콘텐츠 표시, 연속 실패 횟수, 진행 방식 — 보통 안 건드려도 됩니다
- 카테고리·언어 등은 Studio **업로드 기본 설정**을 그대로 따릅니다

## 엑셀 노란 칸 (= 고치기 창의 칸)
| 칸 | 쓰는 법 |
|---|---|
| 제목 | SEO 추천 1순위가 들어가 있음. `제목후보` 칸의 3안을 보고 고치기 |
| 회원우선 | 회원 먼저 공개할 영상만 `O` (엑셀이 O 말고는 못 넣게 막습니다) |
| 예약일시 | `2026-10-21 12:15` 꼴 (`.` `/` 도 됨). **날짜만 적으면 그 요일의 공개 시간**으로. 비우면 다음 빈 자리로 자동. 채널 공개 요일·시간과 다르면 4. 예약 걸기에서 한 번 더 물어봄 |
| 영상ID | 보통 비워둠. "초안을 못 찾았습니다" 오류가 나면 그 영상의 **주소를 통째로 붙여넣기** (`https://youtu.be/…`, Studio 주소 모두 됨) |

- 썸네일 없이 올릴 영상은 고치기 창의 **썸네일 없이 올리기**를 체크하거나 엑셀 `썸네일` 칸에 `없음`이라고 적으세요 (안 그러면 자동 처리가 멈추고 알려줍니다).

## 폴더 규칙 (이것만 지키면 됩니다)
```
영상/
  2026-10-19/          ← 1. 영상 준비의 폴더 만들기가 만듦
    숨겨진동양사/        ← 채널 폴더 (설정의 '영상 폴더 이름')
      아무 폴더나/ 아무 이름이나   ← SEO 메모장, 썸네일 (영상·대본은 있어도 되고 없어도 됨)
    고전/
```
- 짝 찾기: 영상 파일 이름의 번호 = SEO의 순번 (폴더에 영상이 없으면 Studio에 올린 원본 파일 이름으로). 영상 파일 이름에 번호가 꼭 있어야 합니다. 썸네일은 같은 이름 → 같은 번호 → 제목 비슷한 것
- 대본·자막·프롬프트 txt는 읽지 않습니다 (이름이나 폴더에 '대본' 등이 들어 있으면). SEO 메모장만 씁니다
- **채널 폴더 안에** 넣어야 합니다. 묶음 폴더(날짜 폴더)에 바로 둔 파일은 2. 자동 처리에서 알려줍니다
- 채널 폴더의 영상이 다 끝나면 그 폴더째 `완료/2026-10-19/채널/`로 옮김
- 자동 처리를 시작한 뒤에는 **파일 이름·채널 이름을 바꾸지 마세요** (엑셀 행과 짝이 끊김)

## 댓글 답글 (채널마다, 기본은 꺼짐)
- **설정 → 채널 → '댓글 답글'**: 끔 / **확인 후 달기**(초안을 보고 고르기) / **자동으로 달기**
- 공개 후 48시간 안의 새 댓글에 Claude가 **채널 주인 말투로** 초안을 씁니다. 스팸·욕설·이모지만 있는 댓글은 건너뜁니다
- 말투는 고급 설정의 **답글 말투 메모**, 채널이 예전에 단 답글, 고정 댓글에서 배우고, **초안을 고쳐서 달면 그 방향을 기억해** 다음 초안이 점점 닮아 갑니다
- 2. 자동 처리 끝에, 또는 **더보기 → 댓글 답글 달기**. '자동으로 달기' 채널은 창을 켜 두면 1시간마다 확인합니다
- 답글 하나에 YouTube 할당량 50이 들어 한 번에 최대 60개(영상마다 15개)까지만 답니다. Claude 비용은 댓글 6개에 약 2센트

## 되돌리기·문제가 생겼을 때
- **영상 하나를 처음부터 다시**: 목록에서 오른쪽 클릭 → **정보 넣기를 처음부터 다시** → 2. 자동 처리. 원래 초안 틀(백업)에서 다시 합치므로 제목이 두 번 들어가지 않습니다
- **원래 제목·설명**: `_프로그램/백업/영상/<영상ID>.json` 에 바꾸기 전 상태가 남아 있습니다
- **엑셀이 망가짐**: `_프로그램/백업/엑셀/` 에 단계마다 사본이 있습니다 (최근 30개)
- **무슨 일이 있었는지**: **기록** 버튼 → 날짜별 기록
- **로그인 만료**: "로그인이 만료됐습니다" → 설정 → 그 채널 → 로그인

## 청소
- **청소** 버튼 → 지울 것을 골라 **청소하기**. 윈도우에서는 **휴지통**으로 가서 되살릴 수 있습니다
- 기본으로는 시험 결과·오류, 백업, 작업 기록만 골라져 있습니다
- **모두 선택**은 엑셀·영상·완료 파일까지 지웁니다 (⚠ 항목은 한 번 더 확인). 설정·로그인·열쇠 파일은 청소로 지우지 않습니다
- 프로그램 파일은 지우지 않습니다

## 알아둘 것
- YouTube API 하루 한도(모든 채널 합산 10,000)로 **하루 약 40개**(2·4번 합쳐서)까지 처리됩니다. 자동 처리 시작 때 예상치를 보여주고,
  넘으면 멈춰서 알려줍니다. **창을 켜 두면 한국 시간 오후 5시 5분에 자동으로 이어서** 합니다 (꺼 두었다면 그 뒤에 같은 버튼).
