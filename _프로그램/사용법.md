# 사용법

## 처음 설치 (한 번만)
- [LongAutoUpload.zip](https://github.com/kjg0898-dot/LongAutoUpload/releases/download/download/LongAutoUpload.zip) 받기 → 오른쪽 클릭 **압축 풀기** → `LongAutoUpload` 폴더가 생김 (원하는 곳, 예: 바탕화면으로 옮기기)
- **이후 새 버전은 자동**: 프로그램을 켤 때 새 버전이 있으면 알아서 업데이트하고 다시 켜집니다 (몇 초).
  다시 내려받거나 폴더 이름을 바꿀 필요 없고, 열쇠·로그인·설정·영상·엑셀은 그대로 남습니다.
  켜 둔 채로 받고 싶으면 **업데이트** 버튼

## 처음 한 번
1. `구글연동_안내.md`대로 열쇠 파일(`client_secret_….json`)을 받아 이름 그대로 이 `_프로그램` 폴더에 넣기
2. `실행.pyw` 더블클릭 (처음엔 부품 설치로 1~2분, 창이 멈춘 것처럼 보여도 기다리기)
3. **설정** → **채널 추가** → 브라우저에서 그 채널의 구글 계정으로 로그인하고 **채널 선택 화면에서 그 채널**을 고르기 (5분 안에)
   - **나머지는 자동**: 채널 이름·영상 폴더 이름·공개 요일·시간(최근 공개·예약 기록에서)을 채우고,
     "수익 창출 채널인가요?", "회원 기능 쓰나요?" 두 가지만 물은 뒤 저장합니다
   - 숨겨진동양사는 미리 넣어 두었습니다: 설정에서 고르고 **로그인**만 누르세요
   - 설정 위쪽에 "로그인됨: YouTube 채널 '…'"이 그 채널인지 확인. 다르면 다시 **로그인**
   - 제목 넣는 자리 기본값은 Studio 제목 틀의 `]` 바로 뒤입니다. 예) `[숨겨진 동양사] ＜엑셀 제목＞ l 역사 인물 l 고전 | 수면오디오북`.
     제목 틀이 없는 채널(초안 제목이 파일 이름)은 제목을 통째로 바꿉니다

## 화면
- **왼쪽: 단계 카드 0~4** — 지금 할 차례인 카드가 노랗게 표시되고, 카드마다 남은 개수가 나옵니다. 위에서부터 차례로 버튼만 누르면 됩니다.
- **오른쪽: 영상 목록** — 엑셀 내용을 그대로 보여줍니다. 색: 빨강=오류, 파랑=진행 중, 초록=완료, 주황=회원 직접설정
  - **더블클릭(또는 Enter)** → 고치기 창: 제목(후보 3안 버튼으로 바로 바꾸기, 글자 수 표시), 예약일시, 회원 우선, 썸네일 없이, 영상ID.
    **저장하고 다음 ▶**으로 영상을 하나씩 넘기며 확인 (엑셀을 열 필요 없음)
  - **오른쪽 클릭** → Studio에서 열기, YouTube에서 보기, 파일 폴더 열기, 썸네일 없이 올리기, 2단계 처음부터 다시 하기
  - 위쪽에서 **채널별로 보기**, **오류만** 보기. **F5** 또는 새로고침
- **아래: 기록** — 무슨 일이 있었는지 차례로 나옵니다

## 3주마다 — 가장 간단한 방법
1. **0. 폴더 만들기** → 채널 폴더마다 영상·SEO 메모장·썸네일 넣기 → 영상을 Studio에 올리고 초안이 될 때까지 기다리기
2. **▶ 한 번에 진행** → 넣을 제목 목록을 한 번 보여주고 '예'면 1·2단계를 이어서 한 뒤 고정 창을 엽니다
3. 탭마다 댓글 고정 → 고정 창의 **4. 예약 걸기**

단계를 하나씩 하고 싶으면 아래처럼 카드 버튼을 차례로 누르면 됩니다.

| 누가 | 할 일 |
|---|---|
| 카드 **0. 새 묶음 폴더** | `영상/2026-10-19/채널폴더들` 이 생기고 열림 |
| 나 | 채널 폴더마다 영상·SEO 메모장·썸네일 넣기 (안에서는 아무렇게나) |
| 나 | 영상을 Studio에 끌어다 놓고 **업로드가 끝나 초안이 될 때까지** 기다리기 (세부정보는 채우지 않아도 됨) |
| 카드 **1. 엑셀(목록) 만들기** | 못 찾은 메모장·썸네일, 같은 제목 등을 한 번에 알려줌. 파일을 고친 뒤 다시 눌러도 됨 |
| 카드 **제목 확인** | 오른쪽 목록에서 영상을 **더블클릭** → 제목 확인·수정 → **저장하고 다음 ▶**. (엑셀이 편하면 **엑셀로 열기** → 노란 칸 수정 → 저장하고 **엑셀 닫기**) |
| 카드 **2. 정보·댓글 넣기** | 먼저 전부 점검한 뒤, 초안에 제목·설명·태그·썸네일 + 일부공개 + 댓글 |
| 카드 **3. 댓글 고정** | 채널별 버튼 → 탭마다 댓글 고정 (수창 채널은 광고 설문 탭도) |
| 카드 **4. 예약 걸기** | 예약 + 실제로 걸렸는지 확인 + 끝난 채널 폴더를 `완료/`로 |
| 나 | 상태가 **'회원 설정 필요'**인 영상만 Studio에서 "회원 전용 + 공개 예약" 직접 설정 (창에 날짜·시간 안내) |

- 창 아래쪽에 채널별 개수와 **다음 할 일**이 나옵니다.
- 중간에 멈춰도 같은 버튼을 다시 누르면 **끝난 영상은 건너뛰고** 이어서 합니다.
- 실패한 영상은 목록과 엑셀 `오류` 칸(빨간색)에 이유가 적힙니다. 고친 뒤 같은 버튼을 다시 누르면 됩니다.
- **작업 중에는 엑셀을 열지 마세요.** 열려 있으면 닫으라고 물어봅니다.
- 처음에는 설정의 **진행 방식**을 "영상마다 확인"으로 두면 하나씩 확인하며 진행합니다.

## 엑셀 노란 칸 (= 고치기 창의 칸)
| 칸 | 쓰는 법 |
|---|---|
| 제목 | SEO 추천 1순위가 들어가 있음. `제목후보` 칸의 3안을 보고 고치기 |
| 회원우선 | 회원 먼저 공개할 영상만 `O` (엑셀이 O 말고는 못 넣게 막습니다) |
| 예약일시 | `2026-10-21 12:15` 꼴 (`.` `/` 도 됨). **날짜만 적으면 그 요일의 공개 시간**으로. 비우면 다음 빈 자리로 자동. 채널 공개 요일·시간과 다르면 4단계에서 한 번 더 물어봄 |
| 영상ID | 보통 비워둠. "초안을 못 찾았습니다" 오류가 나면 그 영상의 **주소를 통째로 붙여넣기** (`https://youtu.be/…`, Studio 주소 모두 됨) |

- 썸네일 없이 올릴 영상은 고치기 창의 **썸네일 없이 올리기**를 체크하거나 엑셀 `썸네일` 칸에 `없음`이라고 적으세요 (안 그러면 2단계가 멈추고 알려줍니다).

## 폴더 규칙 (이것만 지키면 됩니다)
```
영상/
  2026-10-19/          ← 0. 새 묶음 폴더 버튼이 만듦
    숨겨진동양사/        ← 채널 폴더 (설정의 '영상 폴더 이름')
      아무 폴더나/ 아무 이름이나   ← 영상, SEO 메모장, 썸네일, 대본 등
    고전/
```
- 짝 찾기: 영상 파일 이름의 번호 = SEO의 순번. 썸네일은 같은 이름 → 같은 번호 → 제목 비슷한 것
- 대본·자막·프롬프트 txt는 읽지 않습니다 (이름이나 폴더에 '대본' 등이 들어 있으면). SEO 메모장만 씁니다
- **채널 폴더 안에** 넣어야 합니다. 묶음 폴더(날짜 폴더)에 바로 둔 파일은 1단계에서 알려줍니다
- 채널 폴더의 영상이 다 끝나면 그 폴더째 `완료/2026-10-19/채널/`로 옮김
- 1단계 뒤에는 **파일 이름·채널 이름을 바꾸지 마세요** (엑셀 행과 짝이 끊김)

## 되돌리기·문제가 생겼을 때
- **영상 하나를 처음부터 다시**: 목록에서 오른쪽 클릭 → **2단계 처음부터 다시 하기** (또는 엑셀에서 `상태` 칸을 비우기) → 2단계. 원래 초안 틀(백업)에서 다시 합치므로 제목이 두 번 들어가지 않습니다
- **원래 제목·설명**: `_프로그램/백업/영상/<영상ID>.json` 에 2단계 전 상태가 남아 있습니다
- **엑셀이 망가짐**: `_프로그램/백업/엑셀/` 에 단계마다 사본이 있습니다 (최근 30개)
- **무슨 일이 있었는지**: **기록** 버튼 → 날짜별 기록
- **로그인 만료**: "로그인이 만료됐습니다" → 설정 → 그 채널 → 로그인

## 청소
- **청소** 버튼 → 지울 것을 골라 **청소하기**. 윈도우에서는 **휴지통**으로 가서 되살릴 수 있습니다
- 기본으로는 시험 결과·오류, 백업, 작업 기록만 골라져 있습니다
- **모두 선택(완전 초기화)**은 엑셀·영상·완료 파일·설정·로그인·열쇠까지 지웁니다 (⚠ 항목은 한 번 더 확인)
- 프로그램 파일은 지우지 않습니다

## 알아둘 것
- YouTube API 하루 한도(모든 채널 합산 10,000)로 **하루 약 40개**(2·4단계 합쳐서)까지 처리됩니다. 2단계 시작 때 예상치를 보여주고,
  넘으면 멈춰서 알려줍니다. **창을 켜 두면 한국 시간 오후 5시 5분에 자동으로 이어서** 합니다 (꺼 두었다면 그 뒤에 같은 버튼).
- 작업 중 로그인이 만료됐으면 그 자리에서 "다시 로그인할까요?"라고 묻습니다. '예' → 브라우저에서 그 채널 고르기.
- 댓글 고정·광고 설문·회원 전용은 공식 API에 기능이 없어 직접 합니다.
- 아동용 영상은 댓글을 달 수 없어 건너뜁니다.
- 고정 탭은 기본 브라우저로 열립니다. 브라우저 프로필이 그 채널 계정이어야 고정 메뉴가 보입니다.
