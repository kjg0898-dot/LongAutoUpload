# 구글 연동 설정 (처음 한 번만, 약 20분)

프로그램이 내 채널의 초안을 고칠 수 있도록 "열쇠 파일(client_secret.json)"을 받는 과정입니다.
채널이 여러 구글 계정에 나뉘어 있어도 **이 설정은 한 번만** 하면 됩니다.

> Google 화면 메뉴 이름은 가끔 바뀝니다. 글자가 조금 달라도 비슷한 메뉴를 누르면 됩니다.

## 1. 프로젝트 만들기
1. https://console.cloud.google.com 접속 (아무 구글 계정이나 하나로 로그인)
2. 맨 위 프로젝트 선택 → **새 프로젝트** → 이름 `LongAutoUpload` → 만들기
3. 위에서 방금 만든 프로젝트가 선택됐는지 확인

## 2. YouTube API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `YouTube Data API v3` 검색 → **사용**

## 3. 동의 화면 만들기
1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (또는 **Google 인증 플랫폼**) → **시작하기**
2. 앱 이름: `LongAutoUpload`, 지원 이메일: 내 이메일
3. 대상: **외부**
4. 연락처 이메일: 내 이메일 → 동의 → 만들기
5. **대상(Audience)** 메뉴 → **테스트 사용자 → 사용자 추가**
   → 채널을 가진 **구글 계정을 전부** 추가 (계정이 섞여 있으니 모두)

## 4. 열쇠 파일 받기
1. **클라이언트(Clients)** 메뉴 → **클라이언트 만들기**
2. 애플리케이션 유형: **데스크톱 앱**, 이름 아무거나 → 만들기
3. **JSON 다운로드**
4. 받은 파일 이름을 `client_secret.json`으로 바꿔서 이 `_프로그램` 폴더에 넣기

⚠️ 이 파일과 나중에 생기는 `토큰` 폴더는 비밀번호와 같습니다. 남에게 보내지 마세요.

## 5. 테스트 실행
1. Studio에 영상 하나를 끌어다 놓고 초안이 될 때까지 기다리기
2. `_프로그램/테스트_초안수정.py` 더블클릭
   - 처음엔 필요한 부품을 자동 설치합니다
3. 브라우저가 열리면 그 채널의 계정으로 로그인 → **채널 선택**
   - "Google에서 확인하지 않은 앱" 경고가 나오면: 내가 만든 앱이므로 **고급 → LongAutoUpload(으)로 이동**
4. 창에 초안의 영상ID를 붙여넣기 (Studio 주소 `studio.youtube.com/video/영상ID/edit`의 영상ID 부분)
5. 끝나면 생기는 `테스트결과.txt` 내용을 Claude에게 붙여넣기

## 참고: 로그인 유지 기간
지금(테스트 모드)은 로그인이 **7일마다 풀립니다.** 테스트가 성공하면
**대상 → 앱 게시**를 눌러 "프로덕션"으로 바꾸면 계속 유지됩니다. (경고 화면은 계속 나오지만 본인만 쓰면 문제없습니다.)
