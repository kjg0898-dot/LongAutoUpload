# LongAutoUpload 요구사항 (대화로 정한 내용)

## 방식
- 영상은 사용자가 **Studio에 직접 끌어다 놓음** → Studio 업로드 기본 설정(제목·설명 템플릿, 수익 창출 등)이 초안에 적용됨
- 그 뒤 작업은 **공식 YouTube Data API**로 처리 (크롬 확장/화면 자동 조작은 약관 위반 위험 때문에 제외)
- Windows PC, Python(사용자 PC에 설치되어 있음), GUI 창 하나

## 폴더
```
LongAutoUpload/
  실행.pyw          GUI
  업로드목록.xlsx    제목 수정용 (한 시트, 채널 열)
  영상/             묶음(날짜)/채널 폴더
  완료/             처리 끝난 파일 이동
  _프로그램/         설정·토큰·코드
```

## 채널
- YouTube만, 8개 (늘거나 줄 수 있음), 구글 계정 섞여 있음
- 주제: 명언, 역사
- 수창(YPP) 채널과 비수창 채널이 섞여 있음

## 흐름
1. 사용자: Studio에 영상 올림 → 초안
2. 프로그램: 영상 제작 프로그램이 만든 메모장(txt)의 제목·설명·태그·고정댓글을 엑셀에 자동 채움
3. 사용자: 엑셀에서 **제목만** 수정
4. 프로그램: 초안에 넣기 + 썸네일(사용자가 만든 이미지) + 일부공개 + 댓글 작성
   - 초안에 이미 있는 **템플릿은 남기고**, 템플릿의 자리에 메모장 내용을 넣음 (제목·설명·태그 모두)
   - 영상·메모장·썸네일 파일 짝은 이름이 달라도 최대한 찾아냄. 못 찾으면 알림
   - Studio 초안과 PC 파일은 `fileDetails.fileName`으로 짝 맞춤
5. 사용자: 고정 도우미가 채널별 댓글 화면을 **크롬 탭으로 한꺼번에** 열어주면 고정 클릭
   - 수창 채널은 광고 적합성 설문도 직접 (API 불가)
6. 사용자가 버튼 클릭 → 프로그램이 전부 예약
7. 끝난 파일은 `완료/`로 이동

## 예약
- 3주에 한 번 묶음 작업, 채널당 주 3개 (최대 약 72개/묶음)
- 채널별 요일·시간 설정, 같은 채널 안에서는 **파일 이름 순서**
- 이미 예약된 마지막 영상 다음 빈 자리부터
- 회원 우선: 기본 규칙(채널 묶음의 마지막 영상) + 엑셀에서 영상별 변경
  - 처리 즉시 회원 공개 → 묶음 마지막 업로드 날 예약 시간에 전체 공개
  - API에 회원 전용 옵션이 없으므로 이 영상은 사용자가 직접 설정 (프로그램은 날짜·시간만 안내)

## 설정
- 모든 업로드 설정 기본값은 **"건들지 않음"** (Studio 기본 설정 유지)
- 설정 화면에서 채널별로 바꿀 수 있게: 카테고리, AI 합성 콘텐츠 표시, 재생목록, 구독자 알림, 퍼가기 등
- 진행 단위(영상마다 확인 / 한 번에 전체)도 설정에서 선택

## 오류
- 그 영상만 건너뛰고 계속, Windows 알림 + 창에 실패 목록
- 연속 N번(기본 3, 설정 가능) 실패하면 멈춤

## 구현하면서 정한 것 (바꿀 수 있음)
- 회원우선 영상의 예약일시는 그 영상 차례의 자리(기본 규칙이면 묶음 마지막 날). 엑셀에서 수정 가능
- 2단계에서 일부공개로 바꿈(댓글을 달려면 필요). 회원우선 영상도 일단 일부공개 → 4단계에서 사용자 직접 설정 안내
- 고정 탭은 시청 페이지(watch), 수창 채널은 Studio 수익 창출 페이지도
- 제목 기본: 기준 글자 `|` 앞, 설명 기본: 맨 앞, 태그 기본: 뒤에 추가 (중복 제거, 500자 한도)
- 다시 실행해도 이미 들어간 내용은 두 번 넣지 않음

## 첫 채널: 숨겨진동양사
- 수창 X / 회원 X / 공개: 월·수·토 12:15
- 초안 제목 틀: `[숨겨진 동양사]   l 역사 인물 l 고전 | 수면오디오북` → `]` 바로 뒤에 제목 (구분자는 소문자 l)
- 초안 설명 틀(채널 소개·재생목록·#역사 #야사 #비사 #정사) **위에** 메모장 설명
- 테스트 사용자는 이 채널 계정 하나만. 다른 채널은 하나씩 추가하며 테스트

## 메모장 (SEO) 형식
- 한 txt에 영상 여러 개: `[날짜] 행 N | 순번 N | 제목: 원본 제목` 블록, 블록 안은 `---`로 구역
- 쓰는 구역: `제목 (3안)`(+`추천 1순위`), `설명글 & 해시태그`(통째로 설명, #해시태그는 태그로도), `고정 댓글`
- 엑셀 제목 칸 = 추천 1순위, `제목후보` 칸에 3안 모두
- 폴더: 묶음 하나에 여러 채널. 채널마다 SEO 파일 따로. 해시태그는 설명에만(태그 칸에 넣지 않음)
  - 규칙은 프로그램이 정함: **새 묶음 폴더** 버튼 → `영상/<날짜>/<채널 폴더>/`, 채널 폴더 안은 자유
  - 한 묶음의 한 채널 폴더 안에서만 짝 찾기
  - 영상 ↔ 메모장 항목: 파일 이름의 번호 = 순번, 안 되면 제목 비슷한 것
  - 썸네일: 같은 이름 → 같은 번호 → 제목 비슷한 것
- 채널 폴더의 영상이 모두 끝나면 폴더째(대본·메모장 포함) `완료/<날짜>/<채널>/`로

## 총괄 검토 반영 (2026-10-19, 안정성·API·사용성·기능 4개 관점)
- 잘못된 영상 수정 방지: 파일 이름이 같아도 공개·예약된 것/다른 행이 쓴 것/파일보다 먼저 올라간 것은 제외, 후보가 2개면 영상ID 요구.
  붙여넣은 영상ID가 공개·예약 영상이거나 원본 파일 이름이 다르면 거부
- 다시 실행해도 안전: 2단계 전 원본(초안 틀)을 `백업/영상/<ID>.json`에 남기고 항상 거기서 합침 → 제목 중복 없음
- 엑셀: 시트 이름으로 읽기, 다른 시트 보존, 임시 파일→바꿔치기 저장, 열려 있으면 닫을 때까지 묻기(못 닫으면 백업에 저장),
  단계마다 사본(최근 30개), 날짜만 적은 예약일시는 형식 오류, 회원우선은 O만
- 2단계: 사전 점검(영상 찾기·제목 길이·썸네일) 후 진행, 할당량 예상 표시, 아동용은 댓글 건너뜀, 댓글은 서버 오류로 재시도 안 함(중복 방지)
- 4단계: 같은 시간 겹침·이미 예약된 시간 거부, 예약 후 다시 읽어 확인, 파일 옮기기 실패는 나중에 재시도, 채널 하나 오류가 다른 채널을 막지 않음
- 로그인: 5분 시간 제한, 매번 계정·채널 선택, 다시 로그인하면 저장된 로그인 삭제 후 새로
- 건너뛴 채널(로그인 만료 등)은 성공으로 보고하지 않고 알림
- GUI: 진행 상황(채널별 개수·다음 할 일), 작업 중 버튼 잠금·진행 표시, 첫 실행 안내, 안내/폴더 버튼, 기록 파일, 고해상도 화면,
  설정 창 하나만·닫을 때 저장 확인·채널 복제·폴더 이름 검사, 고정 창에 채널 계정 표시·연 채널 표시, 긴 알림 줄임, 끝나면 알림

## 아직 안 한 것 (필요하면)
