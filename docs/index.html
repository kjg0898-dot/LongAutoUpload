LongAutoUpload

YouTube 채널 운영자가 자기 채널에 올린 영상 초안의 제목·설명·썸네일·댓글·공개 예약을 정리하는 개인용 Windows 프로그램입니다. A personal Windows tool that lets a YouTube creator fill in titles, descriptions, thumbnails, comments and publish schedules for drafts on their own channels.

개인정보처리방침 / Privacy Policy

  • 이 프로그램은 사용자가 직접 로그인한 본인 YouTube 채널에만 접근하며, YouTube Data API로 영상 정보 수정·댓글 작성·공개 예약만 합니다.
    The app only accesses the YouTube channels the user signs in with, and only to update video details, post comments and schedule videos via the YouTube Data API.
  • 로그인 정보와 작업 기록은 사용자의 컴퓨터에만 저장되며, 개발자나 제3자에게 전송·공유·판매하지 않습니다.
    Sign-in tokens and work logs are stored only on the user's computer and are never sent to, shared with or sold to the developer or any third party.
  • Google 사용자 데이터를 광고, 분석, AI 학습에 사용하지 않습니다.
    Google user data is not used for advertising, analytics or AI training.
  • 사용자는 프로그램의 '청소' 기능으로 로그인 정보를 지우거나 Google 계정 권한에서 접근을 해제할 수 있습니다.
    Users can delete stored sign-ins with the app's clean-up feature or revoke access at Google Account permissions.
  • LongAutoUpload's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.
